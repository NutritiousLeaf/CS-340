How do you write programs that are maintainable, readable, and adaptable? 
Writing maintainable and adaptable programs starts with a clean, modular design and consistent documentation. In Project One, I created a CRUD Python module that separated database logic from the rest of the application. Each operation, Create, Read, Update, and Delete, was defined in its own method with clear parameters, docstrings, and exception handling. This separation made it easy to reuse the module in Project Two when I connected it to the dashboard widgets. Because the CRUD class handled all database interaction, I only needed to modify a few lines to change data queries or filters. In the future, this same module could be adapted for other MongoDB-based applications, such as analytics dashboards or inventory-tracking systems, by simply pointing it to a different collection or schema.
How do you approach a problem as a computer scientist? 
I approach problems by first breaking them down into smaller, testable parts and identifying dependencies. For the Grazioso Salvare dashboard, I analyzed the client’s requirements, specific filters for breed, age, and rescue type, and then mapped them to MongoDB queries. I used an iterative approach: designing one widget at a time, connecting it to the CRUD module, testing the output, and refining the visualization. Compared to previous assignments, this project required more attention to data flow and user interaction, so I relied heavily on modular code and consistent naming conventions. In future projects, I plan to continue using this incremental strategy—starting with clear requirements, defining database schemas early, and using frameworks like Dash to prototype client-ready interfaces quickly.
What do computer scientists do, and why does it matter? 
Computer scientists create systems that turn raw data into actionable insights. In this project, my work helped Grazioso Salvare streamline their dog selection process by visualizing data from multiple shelters in a single, interactive dashboard. This reduces manual searching and allows decision makers to filter and compare dogs instantly based on rescue criteria. Projects like this demonstrate how software engineering directly supports organizational efficiency and better decision-making. Computer scientists bridge the gap between data and human needs, translating information into tools that help companies operate more effectively and compassionately.
